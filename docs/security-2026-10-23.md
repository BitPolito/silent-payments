# Dependency security remediation — 23 October 2026

The findings from the [diagnostic review](diagnostics-2026-10-23.md) are resolved.
No advisory was dismissed or excluded from the audits.

## Changes

- Updated the npm lockfile to patched tooling, including Vite 8.3.5,
  Vitest 4.1.12, shell-quote 1.12.0, PostCSS 8.5.31, and Babel 7.29.7.
  Raised the declared Vite and Vitest minimum versions to the tested versions.
- Migrated Tailwind 3 to Tailwind 4.3.3 and its Vite plugin. This removes the
  vulnerable braces/glob dependency chain: the [braces advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)
  lists no patched version. Removed the obsolete PostCSS configuration and its
  direct dependencies, and updated preview packaging accordingly.
- Preserved the theme configuration and adapted custom utilities, shadow names,
  and focus outlines following the [Tailwind upgrade guide](https://tailwindcss.com/docs/upgrade-guide).
  Home mobile and Tools desktop screenshots were pixel-identical in the selected
  before/after comparisons; all current browser tests pass.
- Updated Pillow to [13.0.0](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html),
  Tornado to 6.5.9, and pytest to 9.0.3, covering production, test, and notebook
  requirements. Confirmed QR/PDF exports and an IPython execution smoke check.
- Updated Rust's transitive crossbeam-epoch dependency from 0.9.18 to 0.9.20,
  resolving [RUSTSEC-2026-0204](https://rustsec.org/advisories/RUSTSEC-2026-0204.html).
  Recompiled and verified the generator from the updated lockfile.

The broad migration was first verified in an isolated repository and environment
before application to the working repository. npm 11.21.1, installed temporarily
outside the project, resolved npm 10's `edgesOut` updater failure. A normal
`npm ci` with the existing Node 22 installation also passes with the final lockfile.
